# 🎲 Domínio Químico — Inorganic Chemistry Domino

An educational domino game developed as an academic project to help students learn and review **inorganic chemical functions** through an interactive and gamified experience.

The project was developed as a multidisciplinary application, combining web, backend, database and cross-platform development.

## ✨ Technologies

- React
- Next.js
- TypeScript
- Node.js
- Express
- React Native
- Tailwind CSS
- Git & GitHub

## 🚀 Features

- 🎲 Domino-based gameplay focused on inorganic chemistry
- 🧪 Questions and concepts related to inorganic chemical functions
- 🌐 Web application built with React and Next.js
- ⚙️ Backend services developed with Node.js and Express
- 📱 Cross-platform development with React Native
- 🗄️ Backend and database integration
- 👥 Developed collaboratively as an academic project

## 🛠️ Running the Project

### Frontend (Next.js)
```bash
cd frontend/domino-quimico
npm install
npm run dev
```
The application will be available at: `http://localhost:3000`

### Backend (Node.js + Express)
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```
The backend will run at: `http://localhost:3001`

Make sure to configure the environment variables in the .env file before running the backend.
